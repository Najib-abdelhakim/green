📌 Intégration de la carte UM6P Green Map

7 méthodes prêtes à copier/coller dans n'importe quelle plateforme (CMS, HTML, WordPress, Wix...)
🔍 Vérification de l'accessibilité de votre carte...
1. IFRAME (Recommandée)

Code à copier :

<iframe src="https://um6p1.netlify.app/" width="100%" height="550" frameborder="0"></iframe>
Aperçu :
(aperçu réduit - dans votre site il sera à taille réelle)
2. LIEN HYPERTEXTE

Code à copier :

<a href="https://um6p1.netlify.app/" target="_blank">🌍 Ouvrir la carte UM6P</a>
🌍 Ouvrir la carte UM6P (démo)
3. POPUP / FENÊTRE MODALE

Code à copier :

<button onclick="window.open('https://um6p1.netlify.app/','carte','width=1200,height=800')">🗺️ Voir la carte</button>
4. REDIRECTION AUTOMATIQUE

Code à copier (redirige vers la carte) :

<script>window.location.href = 'https://um6p1.netlify.app/';</script>
⚠️ Ce code remplace la page actuelle par la carte. Utiliser avec précaution.
5. WIDGET JAVASCRIPT (embed)

Code à copier (charge la carte dans un conteneur) :

<div id="greenmap-widget"></div> <script> fetch('https://um6p1.netlify.app/') .then(r => r.text()) .then(html => { document.getElementById('greenmap-widget').innerHTML = html; }); </script>
Charge tout le contenu de la carte dans un div.
6. OBJECT HTML

Code à copier :

<object data="https://um6p1.netlify.app/" width="100%" height="550">Erreur chargement</object>
Méthode alternative à iframe (support variable).
7. EMBED (compatibilité maximale)

Code à copier :

<embed src="https://um6p1.netlify.app/" width="100%" height="550">
Très large compatibilité (navigateurs anciens).

✅ Résumé pour votre plateforme existante

Quel que soit votre langage (PHP, Python, Ruby, Java, C#, React, Vue, Angular, HTML pur, WordPress, Wix, Shopify...) :

  • Intégration la plus simple → copiez la ligne iframe et collez-la dans votre page.
  • Lien simple → utilisez la méthode 2 (lien hypertexte) pour un accès direct.
  • Popup / modale → méthode 3 pour ouvrir la carte sans quitter le site.
  • Widget dynamique → méthode 5 pour charger la carte dans un conteneur spécifique.

Note importante : Votre carte est accessible via https://um6p1.netlify.app/ → toutes ces méthodes fonctionnent immédiatement.
